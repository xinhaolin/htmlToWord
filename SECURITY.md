# Reporting security issues

The repository is maintained by [@xinhaolin](https://github.com/xinhaolin). Use [GitHub private vulnerability reporting](https://github.com/xinhaolin/htmlToWord/security/advisories/new) to report potential security vulnerabilities privately. Use [public issues](https://github.com/xinhaolin/htmlToWord/issues) only for non-sensitive reports. Do not post private documents, credentials or exploitable internal URLs in a public issue.

For deployments, review the resource-resolver policy, caller-supplied filesystem permissions, Chromium installation and process isolation. SDK limits are not OS CPU/RSS quotas. The local playground is intended for loopback validation and has not been assessed as a public multi-tenant service.
